# WorldState BIM V0.2 Research Preview — 发布与证据协议

状态：**发布候选评估协议**，2026-11-17。项目负责人决定以公开数据、合成精确真值和自动化验证支持研究预览。原 [WS-RealRoom 冻结协议](ws_realroom/PROTOCOL.md)及历史结论不变，继续用于未来的工程级真实房间验证；本协议不追溯改变任何历史结果。

## 状态词

- **Research Preview Ready**：本协议内的候选发布门槛全部通过，且可复现材料和限制清楚。它不代表已获得工程精度、质量认证或真实用户效率。
- **Experimental Capability**：功能可以运行，但真实性、适用范围或安全性尚不足以作为稳定能力使用；需要保留已知失败与不确定项。
- **NOT_MEASURED**：没有合格证据，不能以其他数据类型、AI 判断或自动化耗时代替。
- **Engineering Validated**：仅在独立真实场景满足适用的工程验收条件后使用；本协议不会产生此状态。

功能清单分别用 `STABLE / PREVIEW / EXPERIMENTAL / NOT_MEASURED` 描述，不把某一能力的通过扩展到全部产品。

## 研究版发布门槛

以下门槛须在评测结果出现前固定，不允许隐瞒失败或更改测试真值来达标。

1. **可运行与隔离**：全量 Core/产品回归通过；本地 Studio 能加载自生成的合成房间、编辑至少一面墙、保留身份并导出 IFC；默认仅监听回环；原有 Host、Origin、令牌和照片授权保护通过负向检查。
2. **模型交付**：合成示例 IFC4 独立解析及 schema 检查无错误；所有受支持的墙、楼板、门窗几何成功生成；一次确定性参数编辑及一次独立 BIM 应用编辑与回写成功，构件 GUID 集合不变。任何无法同步的外部编辑必须拒绝或明示。
3. **WS-Synthetic**：至少一矩形和一非矩形合成房间、不同视角、低纹理和遮挡真实生成；每个场景具有参考 IR/IFC、RGB、相机、深度、语义/实例及可见性记录。开发与冻结测试分离，冻结后验证 SHA-256，不使用测试真值或输出调参。须实际提交至少一项非真值模型或匹配输出进行测试，报告全部分母、失败和未可评部分；空输出不能称为重建成功。
4. **WS-Agent**：预先声明至少 20 个自然语言任务及期望，通过真实 Agent 和确定性规则基线分别执行；记录全部任务、失败原因、耗时、模型调用、token 及无法获取的费用。不可将模拟输出、测试点击或规则解释标成真实 Agent。任何建议均须经受控工具验证和明确确认，旧建议必须失效。成功率为研究指标，不以特定成功率伪造工程能力。
5. **许可与文档**：可分发示例须为自生成或经逐项核实许可；ETH3D 及其限制数据仅在许可证允许的非商业研究范围内使用。提供安装、运行、可复现命令、测试结果、失败案例和功能级状态。第三方模型的代码、权重和数据许可分别注明；不得将未经确认权重作为商用资产。
6. **已知缺口**：面向用户明确说明 Photo-to-BIM 的适用范围、尺度及语义未知、对应/遮挡风险、缺失的完整实体碰撞检查、无法同步的外部 IFC 修改和任何未完成测试。所有模型结果保留真实观测、推断、模拟与未知的区别。

研究版不要求自行采集房间、现场测距、真人审核、三组真人配对实验、20% 人工节约或三面照片墙重建。人工成本、真实房间精度和真实语义正确性在没有对应实测时仍为 **NOT_MEASURED**。以上指标不是工程级通过。

## 证据隔离

WS-Synthetic 的算法仅取得 `input/<scene>/images` 与允许的相机输入。`reference/<scene>` 保管精确 IR、IFC、深度、实例标签及可见性；仅评测程序读取，且候选和评测输出位于数据集之外。冻结清单对所有输入与参考文件逐个记录 SHA-256，变更后拒绝评测。场景使用随机标识、相同视图数，避免名称或视图数量直接透露构型；正式测试种子保存在参考区，不放入算法输入。

此隔离防止意外泄露，但不能阻止拥有完整本机文件权限的恶意进程读取真值；需要强隔离时应由独立执行环境或人员托管参考。生成器与评测代码公开不意味着随机的冻结参考被提供给待测算法。开发场景结果不能称为盲测，调参应发生在开发集，冻结测试只运行预先选定的算法和参数。

真实公开数据中，扫描衍生平面或 AI 辅助分类不是独立人工真值。扫描作为输入时不得把同源拟合误差称为独立精度；预选参考区域不能由候选模型位置决定。office 和 kicker 继续标为开发集。
