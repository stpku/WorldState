# WS-RealRoom 独立采集和验收协议

目标是在公开授权或明确有权的真实房间，以相同输入、同一质量门槛比较人工 BIM 建模与 Assisted Mode。按房间建立随机 ID；采集者和评测者保管来源/许可，不能向产品运行器提供隐藏答案。

```text
room-ID/
  LICENSE-and-consent.txt          # 原始资料可用范围、可否公开
  capture-manifest.json           # 数据版本、文件 SHA-256、设备/时间/坐标和操作记录
  input/photos/                   # 允许建模的多视角输入
  input/anchor.json               # 至少一项独立标尺，测量方式、精度、照片位置
  input/annotations.json          # 操作者标点、时间及其来源，允许留空
  input/assumptions.json           # 如墙厚假设，标为假设而非实测
  private-reference/dimensions.csv # 独立测量，不作构模/标尺输入
  private-reference/holdout/       # 留出照片，不供候选生成/调参
  private-reference/reference.ifc # 独立建模并标记其测量和不确定性
  runs/manual/                    # 不同操作者及失败运行均保留
  runs/assisted/                  # 不同操作者及失败运行均保留
  reports/                        # 解封参考后由独立评测器产出
```

1. 对房间进行授权核查，决定原始资料能否进入公开仓库。确认照片覆盖可见墙、转角、门窗；记录近远视角与模糊、遮挡情况。
2. 以独立工具测量一项建模尺度参照，记录工具、两个端点、测量值和不确定性；收集平面图、房高或少量人工标注时也要记录操作者和用时。
3. 由不参与候选生成的人员测量至少三项不同墙体相关的长度或高度，记录起终点、测量不确定性；制作标有依据和未知的参考 BIM。参考与 holdout 照片单独保存并计算哈希，先冻结再运行。尺度参照不能同时计作独立评测尺寸。
4. 所有方案输入相同的允许资料和质量门槛。可允许辅助标注，但将其次数、时间、来源显式计入 Assisted Mode；Automatic Mode 不得复用人工标注。不能以校准所用尺寸充当误差结果。
5. 分别记录素材整理、标注、自动执行、人工修改、人工复核的开始结束时间，调用费、GPU 时间、失败和重跑次数；不得排除失败样本。自动运算耗时与人的投入分开。
6. 生成的 IFC 及 IR 冻结并哈希后，由独立评测者解封尺寸、留出图片和参考 IFC；核验尺寸误差、空间关系、未观测部分以及 IFC 工具编辑和回读；保留每次运行和错误。

## 首个完整房间验收门槛（2026-11-13 预先冻结）

在本协议下的新、尚未运行的验收房间上使用。若更改门槛，须先增加版本及原因并更换未使用的验收场景；不得根据本轮 TUM/CRASLAB 开发结果倒推门槛。

- 输入至少 3 张不同视角真实照片，独立建模标尺至少 1 个；至少 3 个独立评测尺寸、2 张留出视角，测量误差本身需小于其对应容差的 1/3。无独立测量时此项未通过。
- 至少识别 3 段参考模型中可见的独立墙体，各墙至少具备有来源的长度、高度和状态。可见墙实例 precision ≥ 0.90、recall ≥ 0.80；未见墙、墙厚及遮挡开口必须是未知或明确假设，不能伪装成实测。仅局部墙体的结果只能标为部分建模。
- 每项独立墙尺寸绝对误差 ≤ max(0.05 m, 2% 的参考值)。留出视角须能对照并人工审查遮挡和明显几何矛盾；此检查不能替代尺寸误差。
- IFC4 独立解析和几何生成均成功；至少一个墙在独立 BIM 建模应用内更改尺寸、保存并重新读取，仍为可参数编辑实体；简单尺寸修改的 GUID 保持率 100%；外部修改须同步回产品 IR 后重新验证。
- 同一输入和质量门槛下至少 3 组可复核的人工及辅助配对运行，公布各阶段和失败次数；每个合格模型的人工时间中位数至少降低 20%，且成功率不低于人工基线。若样本不足，效率目标为 NOT_MEASURED，不能标 release-ready。

合格模型之外不得计算“每个合格模型成本”；如没有通过的模型，分母为零时报告 NOT_MEASURED。当前尚无验收房间、人工基线或这些门槛的结果。
