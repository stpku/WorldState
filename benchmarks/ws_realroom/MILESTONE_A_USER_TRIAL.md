# WorldState Studio：首次真人试用

此工作区仅供 ETH3D kicker 的 **CC BY-NC-SA 4.0 非商业研究**。已载入 29 张照片、其已知相机、2,586 条待核验的去重特征轨迹、CPU 视觉模型和一个既有局部 IFC 草稿。已有墙面来自自动化观察；尺度、朝上方向和墙厚为假设，不是实测值，也不是完整房间或正式验收结果。首次试用期间不要并发修改同一项目。

## 从自己的电脑访问

连接已有授权的 Tailscale 网络后，在 Windows 浏览器直接打开 [WorldState Studio](https://skyswind.tailf4fad8.ts.net:18790/)，首页即为建模工作台，不需要 SSH 隧道。若显示无权访问，请确认 Windows 和服务器位于同一授权 Tailnet，且该设备允许访问 Studio 端口。

服务仅在 Tailnet 上通过 Tailscale Serve 提供 HTTPS；后台进程仍只监听服务器回环地址。Studio 对 Host、Origin 与会话令牌进行检查，仅接受显式配置的精确域名和本机来源，不使用 Funnel。独立扫描审核服务不经此入口发布，应由有权限的审核人员按单独的隔离流程访问。

## 建模操作

1. 首页已载入项目，无需上传或编辑 JSON。左侧选择已有构件；中间查看三维 IFC 和左右照片，右侧检查属性及证据。青线是已求解的投影，红点是对应观察。通过照片上方的下拉菜单切换视角。
2. 点击顶部“新建墙面”，输入新构件编号或使用自动编号，点击“创建候选”。右侧切换到“标注与证据”；默认以四个边界点建模。
3. 左右各选择一张可以看到**同一物理墙面**的照片。避开柜子、白板、隔断、图像边缘及遮挡边缘。在右侧选择 `p1`–`p4`，每个有序角点至少在两个视角中标注。顶部“标注角点”可开启标注；默认先在原图点击，再在放大图中精确点选。标注仅表示操作者的判断，不能把遮挡边界称作完整墙角。
4. 可在左图标记一个特征后点击右侧“寻找跨图对应建议”。特征轨迹只是候选；比较另一张照片中的物理位置后再接受或拒绝。也可点击“AI 分析左图”，查看语义叠加及线段建议；它不会自动区分所有墙实例，家具可能被误识别。接受的视觉建议仍记录其 AI 来源。
5. 点击“求解模型”，查看青色投影与两张原图、三维候选、残差和未知项。三维区域可切换“已保存”和“候选”；候选尚未提交 IFC。修改任何标点后需重新求解；低像素重投影误差并不能证明空间位置准确。已有局部构件与新构件共处同一相机坐标系，但目前各自求解，不能据此宣称连接、房间闭合或联合拓扑已验证。
6. 要导出草稿，请点击“生成 IFC”，逐项检查尺度、墙厚和朝向。没有独立物理标尺时，保持“明确假设”，确认朝上方向与矩形近似后生成版本，再从右上角“导出”下载 IFC 和模型数据。重新生成会依据照片观察重建片段，可能替换已保存的参数修改；请先检查当前版本。系统只导出通过几何检查的近似矩形、竖直四角片段，不通过时请修正或保留失败。
7. 如果新候选不可靠，可选中该候选，在“标注与证据”中的“标注设置”展开“放弃未保存候选”，确认后重新求解并保存其余构件。被放弃的对象和观察仍在操作日志中；已保存构件不能通过此按钮删除。当前观察更改后，旧版本仍保存在服务器工作区，导出入口会暂时拒绝，直到重新求解并保存。

左侧“照片”面板中的“其他兼容工具”保留旧版 IFC 与多视图操作入口。右下角助手可选择本地规则模式；若管理员启用了 Codex Provider，还可选择“AI 建模 Agent”。DSH 尚未连接，本地规则响应不是模型调用。

使用 AI 模式时，先在左右选择两张有权向模型提供商传输的已注册照片，输入目标并确认照片传输。任务运行时可查看实际工具记录；完成后可选择 AI 建议，在照片上查看黄色的未确认区域。若出现已求解候选或参数修改建议，必须先显式选择、检查证据和前后数值，再确认导入或应用。Agent 未必能得到有效候选；没有独立尺度时不能把假设尺寸当作实测值。已完成任务会在服务重启后恢复，中断任务不会自动重试。

项目保存到服务器本机 `~/.cache/worldstate-milestone-a/user-demo-v1/`。新观察按真实操作者记录；已有自动化观察不会变成人工确认。请记录看不清的照片、候选选择、操作困难和失败原因。暂不将此次试用时间声称为正式人工效率对照；正式配对实验仍按 [MODELER_PAIRED_TASK.md](MODELER_PAIRED_TASK.md) 和冻结协议执行。

## 独立扫描审核

经授权的审核人员通过独立隔离入口打开扫描页面，依次下载全场抽样 PLY 和单面 PLY，结合原始两站扫描判断墙、家具、地面或未知；审核可靠边界、物理实例、独立尺寸和不确定度。页面的记录暂存在浏览器内存中，刷新前必须点击“下载审核记录 JSON”，并在授权位置保存。页面不自动认证审核身份，也不会把未审核平面当作真值。若无法判断，保持“未知”。

## 服务管理

服务器已将 Studio 配置为用户级 systemd 服务并启用用户 lingering；Tailscale Serve 使用后台持久配置。服务管理员可用 `systemctl --user status worldstate-studio.service` 检查状态。该操作不应重置其他 Tailscale Serve 或 Funnel 配置。扫描审核服务继续保持独立，不随 Studio 代理发布。

部署时应将服务的 `--trusted-origin` 设置为具体的 `https://域名:端口`，并使用持久磁盘上的 Python 环境、照片工作区和模型权重；不得使用通配符、未受信任的来源或临时目录作为开机依赖。
