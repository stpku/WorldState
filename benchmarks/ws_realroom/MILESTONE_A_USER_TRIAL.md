# WorldState Studio：首次真人试用

此工作区仅供 ETH3D kicker 的 **CC BY-NC-SA 4.0 非商业研究**。已载入 29 张照片、其已知相机、2,586 条待核验的去重特征轨迹、CPU 视觉模型和一个既有局部 IFC 草稿。已有墙面来自自动化观察；尺度、朝上方向和墙厚为假设，不是实测值，也不是完整房间或正式验收结果。首次试用期间不要并发修改同一项目。

## 从自己的电脑访问

先连接已有授权的 Tailscale 网络，在自己电脑的终端保持以下 SSH 命令运行（要求已有服务器账户 SSH 权限；将目标改为授权管理员提供的地址）：

```bash
WS_SSH_TARGET='AUTHORIZED_USER@YOUR_TAILSCALE_HOST'
ssh -N -o ExitOnForwardFailure=yes \
  -L 127.0.0.1:18790:127.0.0.1:18790 \
  -L 127.0.0.1:18791:127.0.0.1:18791 \
  "$WS_SSH_TARGET"
```

在**同一台电脑**的浏览器打开：

- 建模：<http://127.0.0.1:18790/modeler>
- IFC 工作台：<http://127.0.0.1:18790/>
- 独立扫描审核：<http://127.0.0.1:18791/>。请交给未看过待测模型的独立审核人员；页面本身不包含候选模型。

两个服务只监听服务器的本机回环地址，不公开到互联网。不要把地址写成 `localhost` 或更换本地端口：Studio 校验本机 Host 和 Origin。如果 SSH 显示权限错误，请使用已有的 Tailscale/SSH 授权流程；无需向任何人提供密码、Cookie 或密钥。尚未从负责人的电脑验证其 SSH 权限。

## 建模操作

1. 打开建模页后，无需上传或编辑 JSON。左右照片默认显示已有墙片段的支持视图；青线是上次求解的投影，红点是对应观察。先选择其他照片核对投影。
2. 在“创建可见表面”输入新构件 ID，例如 `trial-wall-1`，选“多个已观察边界点”、4 个点，点击“创建墙面候选”。系统会切换到新对象。
3. 左右各选择一张可以看到**同一物理墙面**的照片。避开柜子、白板、隔断、图像边缘及遮挡边缘。给可见表面的四个有序角点分别使用 `p1`–`p4`，每点在至少两个视角中标注。开启“使用局部放大精确点选”：先在原图点击，再在局部图点击精确位置。标注仅表示操作者的判断，不能把遮挡边界称作完整墙角。
4. 可在左图点一个特征后点击“从左图寻找对应建议”。特征轨迹只是候选；比较另一张照片中的物理位置后再接受或拒绝。也可点击“AI 分析左图”，查看语义叠加及线段建议；它不会自动区分所有墙实例，家具可能被误识别。接受的视觉建议仍记录其 AI 来源。
5. 点击“求解当前候选”，查看青色投影与两张原图、三维候选、残差和未知项。修改任何标点后需重新求解；低像素重投影误差并不能证明空间位置准确。已有局部构件与新构件共处同一相机坐标系，但目前各自求解，不能据此宣称连接、房间闭合或联合拓扑已验证。
6. 要导出草稿，请逐项检查尺度、墙厚和朝向。没有独立物理标尺时，保持“明确假设”，确认朝上方向与矩形近似后点击“生成 IFC 版本”，再下载 IFC 和 IR。系统只导出通过几何检查的近似矩形、竖直四角片段；不通过时请修正或保留失败，不能把草稿当成完整工程墙或测量结果。
7. 如果新候选不可靠，可选中该候选并点击“放弃未保存的候选”，确认后重新求解并保存其余构件。被放弃的对象和观察仍在操作日志中；已保存构件不能通过此按钮删除。当前观测更改后，旧版本仍保存在服务器工作区，导出入口会暂时拒绝，直到重新求解并保存。

项目保存到服务器本机 `~/.cache/worldstate-milestone-a/user-demo-v1/`。新观察按真实操作者记录；已有自动化观察不会变成人工确认。请记录看不清的照片、候选选择、操作困难和失败原因。暂不将此次试用时间声称为正式人工效率对照；正式配对实验仍按 [MODELER_PAIRED_TASK.md](MODELER_PAIRED_TASK.md) 和冻结协议执行。

## 独立扫描审核

审核人员打开扫描页面，依次下载全场抽样 PLY 和单面 PLY，结合原始两站扫描判断墙、家具、地面或未知；审核可靠边界、物理实例、独立尺寸和不确定度。页面的记录暂存在浏览器内存中，刷新前必须点击“下载审核记录 JSON”，并在授权位置保存。页面不自动认证审核身份，也不会把未审核平面当作真值。若无法判断，保持“未知”。

## 服务中断后由服务器管理员恢复

演示数据不会自动重建，也不会覆盖已有试用记录。可在服务器仓库根目录手动启动：

```bash
PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 \
  /tmp/worldstate-bim-reset-venv/bin/python -m products.worldstate_bim.studio_server \
  --workspace "$HOME/.cache/worldstate-milestone-a/user-demo-v1" \
  --vision-model "$HOME/.cache/worldstate-round5/upernet-convnext-tiny-ade.onnx" \
  --warm-vision --port 18790
```

另一个本机终端运行：

```bash
/tmp/worldstate-bim-reset-venv/bin/python -m http.server 18791 --bind 127.0.0.1 \
  --directory "$HOME/.cache/worldstate-milestone-a/scan-review-v1"
```

若端口已被占用，先确认占用的是本演示，不要覆盖或停止其他服务。准备新副本时使用 `prepare_kicker_user_demo.py` 并指定不存在的输出目录。
