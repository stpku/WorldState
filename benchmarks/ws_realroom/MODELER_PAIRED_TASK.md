# Modeler 人工与辅助建模配对任务

此文件是可执行的研究任务说明，不是实验结果；正式验收仍以
[`PROTOCOL.md`](PROTOCOL.md) 为准，任何阈值、样本要求和隔离规则均不变。
Playwright、脚本标点和机器计时不能冒充真人工时。

## 开始前

负责人选择有授权的真实房间和至少三段可见独立墙体，准备相同的输入照片、
允许建模的物理标尺、可选已知相机及允许的辅助测量。将独立评测尺寸、留出
照片和参考 IFC 封存；不得向两组建模者泄露。记录测量来源及不确定度，
扫描衍生的尺度应明确标记，不能写成现场测距。预先冻结建模范围、相同的
质量门槛、数据版本和两个工作流的操作说明。

使用不同开发场景进行试用；正式 Room-Test 必须是没有用于调参的新场景。
Kicker 和 office 只能用于开发。选用真实熟练的 Bonsai、FreeCAD 或其他
适用软件操作者；不要故意限制正常高效操作。安排配对顺序交替，并记录
操作者经验、学习和复用情况，避免把不同输入或不同质量模型直接比较。

## 每组操作

1. **人工流程 A**：使用约定照片、标尺和人工 BIM 工具建立约定范围内的
   模型，保存原始工程及 IFC。记录需要确认的未知和假设。
2. **WorldState 流程 B**：使用同一输入，通过 Studio `/modeler` 上传照片、
   导入对应注册相机，创建构件并建立跨图观测。允许使用已批准的自动建议，
   保留接受、拒绝和修正记录；求解、复核后导出 IFC。边到线模式的两个
   推断端点、向上方向、尺度和墙厚均不得记成实测。
3. 对两个 IFC 冻结版本和输入哈希，再由不参与建模的评测人员按协议解封
   真值，检查墙实例、独立尺寸、留出视角及 IFC 编辑回写。失败模型也保留。
4. 两个流程各自记录以下时间及次数：素材整理、人工标注、等待计算、人工
   修改、人工复核、失败重试、自动运行、计算费用、最终是否通过。模型调用
   与 GPU 未使用时写零及原因，未知值写 `NOT_MEASURED`，不得自行估计。

第一组只用于检查操作流程、遮挡和记录方式；正式效率结论仍需至少三组
符合冻结协议的真实人工配对实验，并要求每个合格模型的人工时间中位数
下降至少 20%，成功率不低于人工基线。
