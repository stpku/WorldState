## 结果与复现

完整可执行命令、数据许可与输出见 [benchmark README](../../benchmarks/bim_real_room/README.md)。CPU 照片双视角 66 个点，中位重投影 0.299 px，但采用 oracle 轨迹尺度后 52 点中位深度误差 0.338 m；相对深度模型经**同帧密集真值标定**后留出像素中位误差 0.0178 m；人工选出的 RGB-D 平面 1140/1224 点为内点、拟合残差 0.00824 m。不同传感器/标定信息和样本使三个结果不可直接比较；所有数字均不是独立墙体/BIM 验收。

本轮遇到的失败：系统默认 Python 缺少依赖；DSH headless 缺少模型凭据；完整 TUM 归档下载超时后重启；固定镜像单文件出现过 TLS 意外断开，下载器添加有限重试并保持哈希校验，之后从空目录成功下载全部 6 个数据文件。深度镜像字节尚未与完整官方归档比对。最终 `pytest tests products/worldstate_bim/tests` 为 **146 passed，4 warnings**；在不含用户未提交改动的提交快照中复跑同样通过。警告来自 IfcOpenShell 0.8.4 对 `datetime.utcnow` 的弃用调用。

功能分支已推送；GitHub 集成创建草稿 PR 返回 **403 Resource not accessible by integration**。未创建 PR；可使用 [草稿说明](DRAFT-PR.md) 在具备仓库 PR 写入权限的环境创建，未合并主分支或发布 Release。
