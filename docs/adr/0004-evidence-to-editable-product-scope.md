# ADR 0004：产品范围与可替换的证据到模型管线

状态：2026-11-13 产品方向批准（用户指令）；具体算法、接口和发布门槛仍为提议，待真实数据与独立编辑验证。

## 背景与决策

WorldState 的产品 North Star 是 **Evidence-to-Editable World**；第一产品是 WorldState BIM。现有 AGENTS 与未提交 README 将 WorldState 整体描述为仅有 foundation 的历史阶段，但已提交的 `products/worldstate_bim` 和本轮用户指令要求产品化建模。用户明确授权在产品目录开展视觉、几何和 BIM 能力；这不是放宽 `src/worldstate` Core 的领域中立不变量，也不是授权现有生产系统切换。为保留用户未提交工作，本 ADR 不覆写根文件。

在 `products/worldstate_bim` 下保持独立依赖与数据格式：输入证据 → 可替换重建 → 语义与参数约束 → IFC 编译/预览 → 验证与版本演化；通用 Harness 在仓库外/可替换适配器中执行，DSH 是候选而非唯一实现。GeoTask 负责其任务上下文，AgentReality 负责 grounding，原有 Core 继续表达状态、时效、来源、未知和冲突。不存在强制迁库或跨项目合并。

先以传统多视图几何与基础模型为**可复现候选**，以 IfcOpenShell 编译受约束的构件；实验并不能证明任何模型是赢家。RGB-D、尺度传感器、人工确认必须作为明确输入和成本独立记录。点云/Mesh/新视图不自动获得 IFC 构件语义。未测路线不按供应商结果打分。

## 关键约束

- 所有派生对象及属性保留源 hash、坐标系/单位、时间、观测/推断/模拟、置信与可见范围；无法观测的厚度、背面、尺度不得当成测量。
- 算法建议只产生受约束数据，不能直接写任意 IFC 文本、审批、发布或覆盖客户权威记录。图像发送远端前由产品权限和数据使用约束决定。
- 对象持久 ID 与构件 GUID 映射独立于几何值；增量修订先追踪依赖、只重算影响范围并在新版本中复验；无法关联时保留 Unknown/Conflict。
- Core API/行为、历史和消费者契约保持兼容；生产门禁不因本文被绕开。产品契约升级应显式版本化，旧 `0.1` 的“声明过 anchor”不能冒充被测量或已应用的尺度。

## 决策后果与未决问题

产品可以单独引入 NumPy/OpenCV/IfcOpenShell/模型运行时，但不增加 Core 依赖。初期保留不同算法质量、成本和失败边界；针对少图和密集重叠图可以采用不同路线。单墙的版本化属性证据、长度差异和受控 IFC 读回已经在 [ADR 0005](0005-assisted-wall-and-edit-boundary.md) 中局部实现；墙面拓扑约束、跨模型位置对齐、综合权限与一般差异图仍未实现。必须用一间有公开许可、覆盖完整且拥有独立尺寸/IFC 真值的真实房间完成照片→可编辑 IFC 闭环，TUM 当前序列不能替代该验收。
