# ADR 0006：房间 IR、扫描 Provider 与本地工作台

状态：2026-11-13，**产品实验性实现**。不改变 WorldState Core、冻结协议或发布门槛。

## 决定

在 `products/worldstate_bim` 增加版本化 `worldstate-bim-room-ir/0.3`，保留原有单墙 IR。墙、楼板、门、窗、开口、楼层和空间关系使用稳定对象 ID；参数、分类与节点分别保留来源和观测/推断/人工/假设/未知状态。未知或冲突不得自动成为已知几何，不能为形成完整房间而补墙。

墙端点共享表示已确认的连接；平行、垂直和重合约束参与受控求解，相交约束当前只校验。修改后记录受影响对象、验证开口与边界并新建版本。多层扫描导入时只在同楼层、同标高的墙之间合并精确端点；楼板轮廓默认独立，除非有明确关系。空间当前可导出 `IfcSpace` 和墙边界关系，**没有空间实体几何**。柱梁和通用 BIM 编辑仍未实现。

Cloud2BIM 是可替换的产品 Provider：读其 IFC 几何与外部 ID，生成携带原始证据和假设的 IR，冲突对象隔离，再由受限编译器生成 IFC4。已知哈希样例与公开点云关联；其他源必须提供来源声明，该声明本身未自动验证。重建后的对象关联依赖源 GUID 或未变几何指纹。未知材料和地理位置不从源默认值补齐。

Studio 为本地工作台，读取实际 IR、IFC 几何和可选点云；图片只在本地存储，当前不自动注册或产生新构件。自然语言输入使用确定性规则，不能称为 DSH Agent。外部 Harness 只能通过产品工具接口调用，不纳入 Core。外部 IFC 同步只接受经对象身份、已检查拓扑、属性和全模型几何校验的单项受支持修改；未检查元数据不导入并提示人工复核。

## 依据和限制

公开扫描案例和独立应用操作见[可复现记录](../../examples/bim_real_scan_craslab/room_round3/README.md)；其同场景点级表面指标表明结构恢复仍不可靠。原始 IFC 的 schema 缺项被移除并不代表分类或几何正确。Bonsai 真实交互已验证墙长，墙高和开口的回读仅有程序化测试。多墙拓扑和对象依赖可以通过构造数据测试，真实扫描案例尚未给出经确认的完整房间。任何真实交付都须按冻结的 [WS-RealRoom 协议](../../benchmarks/ws_realroom/PROTOCOL.md) 独立验收。
