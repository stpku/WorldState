# WorldState Independent Roadmap — M5 to M8

**Status:** Active Foundation Roadmap  
**Date:** 2026-08-25  
**Strategic authority:** AgentReality Stack Four-Repository Unified Strategic Specification v3.0

## Executive decision

WorldState continues as an independently evolving, domain-neutral World State Foundation after M0–M4 integration proofs.

North Star:

> **Truth Fidelity**

Counter-metrics:

> **Unsupported State Rate / False Resolution Rate / Stale State Exposure Rate**

This roadmap is owner-native. Lowa, GeoTask and AgentReality are consumers and validation partners, not the only source of WorldState research work.

## M5 — Temporal Validity & Change Semantics

Goal:

> Move from “what is the current state?” to “what changed, when did it stop being supported, and which bounded state keys are affected?”

Required semantics:

- Validity Window / expiry;
- deterministic Snapshot Delta;
- key-addressable State Change Reference;
- explicit `validity_expired` rather than silent removal;
- state change / Unknown / Conflict transitions;
- change provenance references;
- deterministic replay from two immutable snapshots.

First implementation slice:

```text
WorldStateSnapshot(before)
        +
WorldStateSnapshot(after)
        ↓
diff_snapshots(...)
        ↓
WorldStateDelta
  └── StateChangeRef[]
```

v0.1 intentionally excludes event infrastructure, distributed subscriptions, databases and task semantics.

Exit evidence for the first slice:

- same snapshots → same Delta ID;
- unchanged keys are absent from Delta;
- validity expiry is explicit;
- Unknown / Conflict transitions remain explicit;
- duplicate state results for one key fail closed;
- wire payload is consumer-neutral;
- repository tests remain green.

M5 is not complete merely because the first slice exists. Follow-on work should validate historical replay and provider-side change projection without adding task semantics.

## M6 — Unknown / Conflict Fidelity

Goal:

> Preserve uncertainty instead of manufacturing a single value.

Research / engineering focus:

- Unknown → resolved transitions;
- conflict persistence;
- conflict resolution policy provenance;
- source disagreement;
- unsupported resolution prevention;
- explicit false-resolution benchmark.

First implementation slice:

```text
ReferenceResolver
→ Unknown / Conflict by default
→ optional explicit ConflictResolutionPolicy
→ ConflictResolutionDecision
→ StateAssertion OR preserved Conflict
```

The first slice deliberately keeps source-authority meaning outside Core. Core owns the explicit policy contract, exact candidate coverage, policy identity/version binding, decision lineage, and fail-closed application boundary. The benchmark-local source-priority method is only a deterministic proof vehicle.

Frozen benchmark result:

```text
Baseline Useful State Coverage   66.67%
Policy Useful State Coverage    100.00%
Useful coverage delta           +33.33 pp
False Resolution Rate             0.00
Conflict Preservation Rate      100.00%
Unknown Preservation Rate       100.00%
Policy Provenance Coverage      100.00%
Unknown → resolved transition      PASS
Safety / Utility / Promotion       PASS
```

Frozen safety threshold:

```text
False Resolution Rate = 0
```

Mutation evidence must fail the gate when source priority is reversed or an ambiguous Conflict is forced into a value.

Exit gate:

> Resolution improves useful state coverage without increasing False Resolution Rate beyond the frozen threshold.

The first slice satisfies this gate on the deterministic M6 fixture. M6 remains open for broader conflict-policy generalization and real provider disagreement evidence before any universal resolution-policy claim.

## M7 — Change-Aware Provider & Projection SDK

Goal:

```text
External SoR
→ read-only projection
→ validity/change event
→ WorldStateProvider / change wire
→ consumer
```

Requirements:

- no forced WorldState persistence ownership;
- consumer-neutral contract;
- provider failure remains explicit;
- stable semantic IDs;
- replayable change output;
- no GeoTask requirement or Lowa domain vocabulary in Core.

## M8 — Independent Consumer Generalization

Goal:

> Prove WorldState remains useful outside the Lowa-centered stack path.

Exit gate:

- at least one independent non-Lowa consumer/domain;
- no Core fork;
- no domain-specific resolver branch;
- Truth Fidelity metrics remain meaningful;
- adapter removal does not remove WorldState’s independent utility.

## Strategic invariants

```text
WorldState owns World truth semantics.
WorldState does not own Task semantics.
WorldState semantic ownership does not imply persistence ownership.
Tool/model output is not automatically Truth.
Unknown is not False.
Conflict is not a value-selection inconvenience.
Change must remain replayable.
Foundation-local evolution does not wait for Lowa backlog.
```
