# WorldState Engineering Roadmap — M0 to M4

**Strategic objective:** establish WorldState as an independently useful, open World State Contract / Foundation before integrating it into GeoTask, AgentReality, or Lowa.

---

## M0 — Contract & Semantic Foundation

**Status:** PASS — 2026-08-18

### Goal

Freeze the smallest coherent public semantics for evidence-grounded world state.

### Deliverables

- immutable Core value objects;
- `EpistemicMode` with observed/inferred/predicted/simulated separation;
- first-class `Unknown` and `Conflict`;
- `StateQueryResult` union;
- deterministic semantic ID helpers;
- synchronous `WorldStateProvider` protocol;
- invariant and determinism tests;
- normative Core specification;
- first ADRs;
- explicit license decision;
- basic CI.

### Exit gate

```text
Contracts stable enough to build a resolver
without introducing storage/task/domain assumptions.
```

---

## M1 — Deterministic Reference Resolution Engine

**Status:** PASS — 2026-08-18
**Evidence:** `docs/reports/m1-reference-engine-validation.md`

### Goal

Build the smallest useful reference implementation of Evidence-Grounded State Resolution.

### Deliberately weak baseline

```text
matching supported claims
  ↓
none                 → Unknown
all materially agree → StateAssertion
material disagreement→ Conflict
```

No implicit ranking by newest source, source type, or confidence.

### Deliverables

- in-memory observation/evidence/claim registry;
- conservative resolver;
- validity filtering;
- provenance aggregation;
- immutable snapshot builder;
- evidence lookup;
- state transition/history support;
- replay/determinism tests;
- reusable provider conformance suite.

### Exit gate

```text
Same bounded inputs + same policy + same as_of
→ same semantic result and stable IDs.
```

---

## M2 — Projection & Provider Conformance

**Status:** PASS — 2026-08-18
**Evidence:** `docs/reports/m2-provider-parity.md`

### Goal

Prove that WorldState semantics do not imply WorldState data ownership.

### Proof A — Projection mode

Build a tiny example System of Record that remains authoritative, then expose it through a read-only WorldState projection.

Required proof:

```text
Business data stays in external SoR
        ↓
read-only projection
        ↓
WorldStateProvider
        ↓
identical semantic conformance tests
```

### Proof B — External provider mode

Implement a provider that does not use the reference engine internally.

### Deliverables

- projection adapter example;
- external provider example;
- provider conformance package/tests;
- parity report;
- provider failure → explicit Unknown semantics test.

### Exit gate

```text
Native reference engine, projection provider,
and external provider all satisfy the same contract.
```

---

## M3 — Cross-Domain Generalization

**Status:** PASS — 2026-08-18
**Evidence:** `docs/reports/m3-cross-domain-generalization.md`

### Goal

Pass the WorldState Independence Test in unrelated domains before Lowa migration work begins.

### Scenario selection rule

Choose two domains that differ materially in:

- entity type;
- update cadence;
- source type;
- uncertainty structure;
- temporal behavior.

Examples may include a simple physical-sensor scenario plus a public-record/status scenario. They MUST remain examples, not Core vocabulary.

### Required metrics

- State Correctness;
- Provenance Coverage;
- Unknown Fidelity;
- Conflict Preservation;
- Validity Accuracy;
- Replayability;
- Unsupported State Rate.

### Exit gate

```text
Second domain requires no semantic Core fork
and no domain-specific branch in the resolver.
```

---

## M4 — Integration Proofs, Still No Production Cutover

**Status:** IN PROGRESS — compatibility fixture PASS; cross-repository promotion deferred until stable sibling checkpoints
**Evidence:** `docs/compatibility/stack-observation-2026-08-18.md`

### Goal

Prove interoperability with the wider AgentReality Stack without changing production authority.

### GeoTask proof

```text
WorldStateProvider
      ↓
GeoTask ContextProvider adapter
      ↓
Task Context construction
```

WorldState MUST NOT gain Task semantics as a result.

### Lowa proof

```text
Lowa Business SoR
      ↓ read-only projection
WorldStateSnapshot
      ↓
shadow consumers only
```

No Lowa data migration and no production replacement in M4.

### AgentReality proof

WorldState only supplies snapshot/state/change references. Grounding semantics remain in AgentReality.

### Exit gate

```text
WorldState remains independently useful after all adapters are removed.
```

---

# Promotion beyond M4

Any production replacement of an existing Lowa capability is governed by the wider stack Promotion Gate:

```text
LOCAL_AUTHORITY
→ CONTRACT_MAPPED
→ SHADOW_VERIFIED
→ PROMOTED
```

WorldState project success alone is not authorization to migrate Lowa production ownership.

---

# Explicitly deferred

The roadmap does not schedule these until evidence requires them:

- production database selection;
- distributed deployment;
- hosted service;
- graph server/query language;
- event platform;
- vector database;
- UI console;
- MCP/Agent tool packaging;
- commercial control plane.

The project should earn each of these through demonstrated semantic need rather than architectural aesthetics.
