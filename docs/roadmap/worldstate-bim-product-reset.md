# WorldState BIM 产品路线图：2026-11-13 重置

目标是从真实证据得到可编辑、可迭代、可复用、可验证的模型，并减少达到约定质量所需的人工成本。所有状态均基于真实可复现证据；未满足门槛不得标记 release-ready。现有 `proposal/0.1` 合成 IFC 与本轮两种照片研究实验均不构成 V0.2。

| 版本 | 用户结果 | 必须验收的证据 | 当前状态 |
| --- | --- | --- | --- |
| V0.2 | 公开授权的真实房间少量照片 + 核查的独立尺度 → 墙体候选和 IFC4 草稿 | 每个候选有照片区域/属性来源，独立尺寸与留出视角对照，未知厚度/高度显式处理，独立 BIM 工具修改与回读；安装命令、失败案例和许可 | **IN PROGRESS，未达标**。已贯通 RGB-D 照片到局部墙 IFC、手动修订和本地界面；尺度仍为同传感器参照，缺独立房间测量、完整墙体/语义和真实用户成本。 |
| V0.3 | 多种真实房间墙、门、窗、楼板、柱梁及空间 | 开口实体与关系、楼层/空间拓扑、尺寸修改、IFC 导入重导出、真实几何与语义指标 | 规划。 |
| V0.4 | 证据充分且获授权的建筑单体 | 多视角与尺度、立面/层级/轮廓、语义与遮挡未知、独立测量及留出视角 | 规划。校园历史照片不可视为自动提供公制尺度。 |
| V0.5 | 可替换 Harness 建模、多轮自然语言局部修改 | 实际 DSH 或替代实现的工具调用/失败恢复、影响范围、稳定 GUID、前后误差和人工耗时 | 规划；当前 DSH 最小 headless 请求缺少凭据。 |
| V0.6 | 新证据触发变化定位与版本化局部修订 | 关联、冲突、历史回放/回滚、局部重验与真实后续照片 | 规划。 |
| V1.0 | 可安装可用的证据输入、建模、交互、IFC 和验证产品 | 真实室内与建筑各一类、独立 benchmark、版本历史、成本基线、文档/许可与已知限制 | 规划。 |

## V0.2 门槛（对尚未运行的新验收场景冻结）

选公开可重用、可测量且墙面覆盖充分的房间，区分建模照片、标尺、独立测量和留出照片。冻结的量化几何、语义、独立应用编辑回读和人力成本条件见 [WS-RealRoom 协议](../../benchmarks/ws_realroom/PROTOCOL.md)；尚未对该验收场景运行。若缺少任何一项，状态为未达标。

建立人工基线：相同参与者/时间记录从素材整理到达到质量门槛的传统手工建模、修订与复核耗时，与辅助流程的总人工时间、成功率和总成本对照；先公开样本与统计方法，再设置效率改进目标，不凭推理速度代替人工成本。

## 近期顺序

1. 获取具有完整墙证据和独立尺度的授权真实房间，完成冻结协议的数据隔离和独立参考。
2. 扩展目前单块墙的 assisted IR，支持多个具有明确关系的墙、方向、约束和局部修改；保留用户标注成本。
3. 对同一场景测试可商用视觉模型、SpatialLM/Cloud2BIM 等可用 provider，并在具备 GPU 时试混元生成与修订；未运行者持续标 NOT_TESTED。
4. 扩展当前单墙长度读回到更多属性、构件和拓扑，完成留出视角与尺寸误差；测人工基线和失败成本，达标后考虑 V0.2 release candidate。
